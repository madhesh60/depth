Why this is trustworthy, not just a detector

See

YOLO11 runs full-frame through OpenCV 5 cv2.dnn (no torch at inference). The mission-critical fishing_gear class runs at a hot threshold to catch small crab-pots.

Prove

A real object on the seabed casts a dark acoustic shadow — like a person under a streetlight. We measure it and estimate object height. The stronger discriminator is a re-look: zoom in and re-detect — real objects persist, speckle doesn't.

Decide

A deterministic, human-gated agent calls tools in sequence and triages each find into CONFIRMED / REVIEW / REJECTED — recording every tool call. Nothing is ever deleted: REJECTED is kept for audit.

Act

Confirmed hazards become a nearest-neighbour recovery route and geotagged reports a boat crew can load. GPS is honest: no coordinates are invented when the file has none.

Design principle: honesty first. On this crab-pot sonar the shadow is only measurable on a minority of objects, so it is shown where it exists and never used as a silent gate — the re-look persistence is what earns a CONFIRMED (precision ≈0.79 vs ≈0.61 raw).
