## Decisions

1. **Probability shown to people** (gate registered first: test log-loss) — **detector-only**. test log-loss 0.6368 (detector only) -> 0.6478 (with the OpenCV evidence): not better calibrated - people keep seeing the detector-only calibrated P(pot).
2. **Agent actions** (gate registered after (1) failed, judged on the fresh split only) — **detector-only by default**. on the fresh split: ACCEPT precision 0.86 -> 0.848 (FAILED); real targets left in WATCH 127 -> 161 (FAILED).

So the evidence-driven actions are **off by default**. The studio can switch them on as **Active vision (experimental — not validated)**: the loop is real (every tool call, belief update and conflict is measured and logged), but its benefit is not established beyond the crab-pot test split. What stays on by default is validated or physical: Stage-1 geometry -> geolocation, routes and re-survey passes (STUDY-12), the water-column rule, information-ranked passes and human control.

Costs used to order the tools (measured on this machine): `geometry_check` 0 ms, `shadow_check` 1.47 ms, `zoom_relook` 393.8 ms.

Assumptions: shadow and re-look are conditionally independent given the truth within a band; an opposite-side pass is modelled as one more shadow observation (no paired passes in the data to measure it); thresholds accept 0.60 / watch 0.15 are design constants, not fit.

The calibrated tiers are unchanged: every candidate ≥ τ_review is still a REVIEW card, so the recall promise in `calibration.json` holds exactly as before. The evidence changes the belief, the order of the queue, the action and the re-survey plan — never whether a person sees a find.
